# Zenith · 天顶剑

> 泰拉瑞亚的终极之刃，在 Minecraft 中重建。

一个面向 **Forge 1.20.1** 的小型武器模组，只做两把剑：**天顶剑**与**真铜短剑**。

---

## ⚔️ 模组内容

两把武器共用同一套机制。**按住右键蓄力**：每个 tick 按你的**攻击速度**累积能量，每攒满
**3.33 点**能量就甩出一把飞剑；松开右键时，攒下的能量会在同一瞬间全部倾泻成一轮齐射。
所以攻击速度决定剑的数量，攻击伤害决定每把剑的威力。

甩出的飞剑不是贴图特效，而是真实飞行的物体：沿**真正的椭圆弧**飞行，每一帧重新追踪目标，
带**定向包围盒扫掠碰撞**（不会因高速而穿模）、贴身**动态光照**与**绸带拖尾**。

### 天顶剑（Zenith）

泰拉瑞亚的终极之剑。下界合金级剑，**+19 攻击伤害**，史诗稀有度，不可堆叠。

甩出的飞剑从 **21 把不同的剑**中随机抽取——铜短剑、光之驱逐、村正、泰拉刃、血腥屠夫、
星怒、附魔剑、养蜂人、草剑、炽焰巨剑、永夜刃、真永夜刃、断钢剑、真断钢剑、无头骑士剑、
种子弯刀、真泰拉刃、波涌之刃、狂星之怒、喵刀——以及天顶剑本体，在 **33%** 的发射中强制出现。

### 真铜短剑（True Copper Shortsword）

属性与天顶剑**完全相同**——它就是天顶剑那个外观变体。

唯一的差别在表现：手持真铜短剑时，**你甩出的每一把剑都会固定变成铜短剑**。
没有随机，没有轮换，没有例外。

### 属性对照

| 物品 | 攻击伤害 | 稀有度 | 堆叠 | 特性 |
| --- | --- | --- | --- | --- |
| **天顶剑** | +19（下界合金级） | 史诗 | 否 | 飞剑为 21 把随机抽取，33% 为天顶剑本体 |
| **真铜短剑** | +19（下界合金级） | 史诗 | 否 | 飞剑固定为铜短剑 |

两件物品都可在专属的 **天顶** 创造模式标签页中找到。

### 获取方式

- **无序合成互相转换**：天顶剑 ⇄ 真铜短剑。设定上它们本就是同一把武器。
- **末地城战利品**：天顶剑有 **1%** 概率出现在末地城宝箱中。

## ⚙️ 运行要求

| | |
| --- | --- |
| **Minecraft** | 1.20.1 |
| **加载器** | Forge 47.4.20+ |
| **前置依赖** | [Lyra](https://github.com/CHUJIAN-afk/Lyra) 1.20.1.14+（必需） |
| **安装侧** | 客户端与服务端 |

本模组构建于 **Lyra** 附件实体引擎之上——实体调度器、渲染调度器、网络同步层与动态光照
调度器都由它提供。Forge 侧由 **PortLib** 提供 NeoForge 风格的事件、注册表、附件与网络接口，
已随模组内置（jarJar），无需另行安装。
